# Validation Reference

## Team Composition Constraints

- Tech Lead: 1
- Backend Developer: 0–5
- QA Developer: 0–5
- Reviewer: 1–5

## Checklist

- Verify all task items have an assigned role, objective, preconditions, and expected deliverables.
- Verify the Tech Lead's output contains no code writing, test writing, or direct review activities.
- Verify a brief progress report is output to the user after each agent completes.
- Verify the Reviewer agent was invoked immediately after plan creation.
- If QA or review phases were skipped, the skip reason and remaining risks must be stated.
